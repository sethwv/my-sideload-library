# Account

Open the account menu to choose **Auto**, **Light**, or **Dark** appearance. The selection is stored in that browser for up to a year, so it does not automatically follow the account to another device.

{% include screenshot-pair.html id="account-appearance" %}

Select **Account** to change your password after entering the current one. If the server has SMTP configured, the **Email** tab lets you manage your email address and opt into the weekly new-book digest. Self-service password reset appears at sign-in only when SMTP, a Public URL, and the administrator's Password reset setting are all configured.

{% include screenshot-pair.html id="account-preferences" %}

Some accounts can create one passwordless e-reader bookmark link. Bookmark it immediately in the e-reader browser. Treat it as a password: anyone who has it can browse, download, and use editable shelves as you. Regenerating it invalidates the old link. Bookmark sessions cannot change account settings or use administration.
