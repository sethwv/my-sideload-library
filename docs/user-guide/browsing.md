# Browsing

The Library is the home page after sign-in. It shows books indexed from the EPUB folders configured during deployment.

Search by title, author, or series. Use **Sort by** to order results by title, author, series, date added, or release date, then reverse the direction when needed. Pagination preserves the current search and sort choices.

{% include screenshot-pair.html id="library-controls" %}

Select a cover to open its details. The panel links to its author and series, shows its description and indexed location when available, and contains download and shelf controls. The location identifies the configured library folder that supplied the book. It is not a file-browser link.

Use **Authors** and **Series** in the navigation for their complete indexes, or select an author or series from a book panel to browse that group.
