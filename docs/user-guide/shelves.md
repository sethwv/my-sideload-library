# Shelves

Shelves keep reading lists separate from the server's EPUB folders. Every user has the personal, protected **Favourites** shelf.

## Save a book quickly

Open a book to use **Favourites** and, after you create another personal shelf, a second quick control. That second control is the most relevant shelf for the book: a personal shelf already containing it takes priority, otherwise it is your most recently used personal shelf. Select a control again to remove the book.

{% include screenshot-pair.html id="book-shelves" %}

The controls update without reloading the page. A change made in the expanded picker is reflected in its matching quick control, and the Recent name can change after each successful update.

{% include screenshot-pair.html id="shelf-control-sync" %}

## Use every available shelf

Select the arrow beside the quick controls to open **More shelves**. The picker lists shelves you can use and includes **Back** to return to the book. The pencil opens Account shelf management when you have permission.

{% include screenshot-pair.html id="shelf-picker" %}

Open **Account** then **Shelves** to create a personal shelf, browse it, rename it, or delete it. New shelves are private. A shelf owner can make it shared or public when permitted and can add enabled users as members. Members can add and remove books. Public non-members can read a public shelf but cannot change it.

{% include screenshot-pair.html id="account-shelves" %}
{% include screenshot-pair.html id="shelf-settings" %}

From a shelf page, **Download** opens individual EPUB or KEPUB links for books on the current page. It is not a ZIP or full-library export.
